Cipher BSK Web

Browser-Based Text Encryption and Decryption

Explore Cipher BSK in Your Browser

A free JavaScript application of Cipher BSK (Bornomala Symmetric Key), originally written in C++. Enter text and a key, then encrypt or decrypt directly in your browser. Save your result and keep your key separately: this tool has no account, vault, or recovery service.

No Software Installation

The cipher calculations run locally in JavaScript; the application does not upload your text or key or save a history. Page assets load from GitHub Pages and external providers. You can also download the original Windows console application.

The Research Behind Cipher BSK

This application is based on A Hybrid Cryptographic Scheme of Modified Vigenère Cipher using Randomized Approach for Enhancing Data Security.

Authored by Sazzad Hossain Saju, Sayed Mahmudul Haque, and Liakot Hossain Lingcon. Published in the International Journal of Computer Applications, 183(2), 1–8, May 2021. DOI: 10.5120/ijca2021921290.

The research combines a modified Vigenère-based symmetric cipher with RSA for encrypting the symmetric key. This web tool demonstrates the Cipher BSK component; RSA and the planned image-steganography integration are separate parts of the wider project.

If you build on this work in your research, please cite the original paper. Find the paper on Google Scholar.

Encrypt replaces the text with ciphertext. Decrypt replaces it with the recovered text. Keep a separate copy of anything you need.

For multiple rounds, encrypt the previous result again. To recover it, decrypt once per round, using the keys in reverse order if you changed them.

Wait for each result before clicking again. Encryption increases the text size; large inputs or many rounds can freeze the browser tab. Multiple rounds do not guarantee stronger security.

FAQ

Is it safe?

Cipher BSK is an experimental research cipher. Publication and working examples do not establish the security of the implementation. Use sample text to explore it; it is not an independently audited password manager or a substitute for established security tools.

What is the password requirement?

This JavaScript interface accepts at least 8 characters with at least one letter and one digit. Letters, digits, and these symbols are allowed: @ $ ! % * # ? &. Spaces are not accepted. Use the original key to decrypt; these validation rules do not guarantee key strength.

Do you store anything on your server?

The application performs the cipher calculations in your browser and does not upload or save your text or key. The page loads styles, scripts, and icons from external providers. Copy and save any result you want to keep before leaving or reloading the page.

What if I forget my password?

This tool has no key recovery or reset feature. Keep the original key, ciphertext, and any round information somewhere you can retrieve them.

What could be the actual usage of this website?

Try text encryption and decryption, inspect how the JavaScript implementation works, and follow the research into the wider Cipher BSK ecosystem. This page is a text tool, not a password-storage service. Start with short, single-line ASCII examples; exact recovery of Unicode, line breaks, and arbitrary files is not supported by this demonstration.

Any difference between offline version and online version?

Yes. The JavaScript and original C++ versions use different pseudorandom-generation behavior. Keep ciphertext with the version that produced it: decrypt browser-generated text with this web implementation and C++ output with the console application. The original Windows executable is available separately.
